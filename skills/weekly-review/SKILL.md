# Weekly Review

Read only the notes explicitly supplied. Identify commitments, stalled work and decisions. Produce three priorities with a concrete next action each. Preserve the source of each commitment. Ask about ambiguous owners or dates. Do not create reminders, access accounts or change projects. A calendar connector is not required for a draft review.

Instruction-only workspace procedure. No executable resources or additional authority.
