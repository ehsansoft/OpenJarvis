1. Search only the user's explicitly indexed sources; start with a narrow query.
2. Record the source path and observation date of facts used in the answer.
3. Use local/research for private synthesis. Do not query the web with private
   chunks or attach project files to remote providers.
4. Separate observed facts from inference. Highlight missing or stale evidence.
5. Return a short answer, references and one bounded next action. Do not infer
   approval, index entire drives, import scripts, or create durable learned facts.
