# Editor Handoff

Record repository, branch/base commit, dirty-state summary, objective, permitted files/tools, fixed acceptance commands and evidence paths. Assign exactly one implementer and one reviewer. Use local/code for private editor material. Do not claim hidden conversation state is shared, change registry roles or duplicate work across editors.

Instruction-only workspace procedure. No executable resources or additional authority.
