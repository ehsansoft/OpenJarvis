---
name: private-project-plan
description: Plan one bounded private repository task with evidence, validation and a review boundary.
allowed-tools: file_read git_status git_diff think
---

1. Identify the selected repository and read its AGENTS.md before planning.
2. Inspect branch, dirty state and relevant documentation with read-only tools.
3. Propose one bounded task, expected behavior, files involved and focused checks.
4. Preserve dirty work, sources, databases, models and canonical render evidence.
5. Route private repository content through local/code. Never send it to a free
   remote provider without explicit permission for that specific material.
6. Return the plan and evidence. File edits, deletes, migrations, publication and
   deployments require their applicable authorization; this skill grants none.
