# Bounded Debugging

Use the selected error and code excerpt. State expected and observed behavior, a minimal reproduction, ranked causes and a focused regression. Mark missing evidence. A hypothesis is not a verified cause. Do not run commands, edit files, install dependencies or read additional repositories without an assigned editor task and permission.

Instruction-only workspace procedure. No executable resources or additional authority.
